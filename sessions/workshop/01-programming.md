# کارگاه برنامه‌نویسی ۱ — محیط C و اجرای برنامه

**وضعیت:** Prepared  
**زمان:** ۱۰۰ دقیقه  
**هدف:** دانشجو بتواند برنامه C را مستقل ذخیره، کامپایل، اجرا و آزمون کند.

## پیش از جلسه
- مدرس/دستیاران محیط‌های قابل استفاده دانشجویان را بررسی کنند.
- یک دستور کامپایل مشترک و یک راهنمای کوتاه برای محیط دانشگاه آماده شود.
- اگر IDE متفاوت است، معیار ارزیابی خروجی و توانایی اجرا باشد، نه نام IDE.

## برنامه
- ۰–۱۵: بررسی محیط و ساخت پوشه کار.
- ۱۵–۳۰: نمایش چرخه ذخیره، کامپایل، اجرا.
- ۳۰–۴۵: تمرین فردی: Hello World و خواندن/چاپ یک عدد.
- ۴۵–۶۵: تمرین فردی: دو عدد و مجموع؛ دانشجو کد را اجرا کند.
- ۶۵–۸۰: آزمون عملی کوتاه: خطای syntax داده‌شده را اصلاح و برنامه را اجرا کند.
- ۸۰–۹۵: بررسی چند خطا و خروجی‌ها.
- ۹۵–۱۰۰: ثبت چک‌لیست.

## معیار قبولی
- فایل با پسوند و نام مناسب ذخیره شده است.
- برنامه بدون خطای کامپایل اجرا می‌شود.
- دانشجو ورودی/خروجی را تغییر می‌دهد و دوباره اجرا می‌کند.
- دانشجو می‌تواند خطای ساده را تشخیص دهد.

## خروجی قابل ثبت
فایل منبع C و یک یادداشت کوتاه شامل دستور/روش اجرا و یک ورودی آزمون.
