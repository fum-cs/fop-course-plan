# جلسه نظری ۴ — تکرار با while و for

**وضعیت:** Prepared — بازنویسی‌شده؛ هنوز در کلاس آزموده نشده  
**زمان:** ۱۰۰ دقیقه  
**پیوند Roadmap:** جلسه ۴  
**منبع:** درس‌نامه، بخش ۳

## هدف‌های یادگیری
- تکرار را با `while` و `for` پیاده‌سازی کند.
- شمارنده، مقدار اولیه و شرط توقف را درست انتخاب کند.
- اجرای حلقه را با trace خطوط واقعی C دنبال کند.
- خطاهای off-by-one و حلقه بی‌نهایت را تشخیص دهد.

## طرح زمانی
- ۰–۱۰: مرور شرط؛ یک شرط ساده روی تخته.
- ۱۰–۲۵: حلقه `while` و اجرای مرحله‌به‌مرحله.
- ۲۵–۴۰: `for` و اجزای آن؛ تبدیل یک حلقه به شکل دیگر.
- ۴۰–۵۵: مثال جمع و شمارش.
- ۵۵–۷۵: تمرین مستقل؛ بررسی چند کد دانشجو.
- ۷۵–۹۰: حلقه‌های مرزی، صفر بار اجرا و یک بار اجرا.
- ۹۰–۱۰۰: مسئله خروج و جمع‌بندی.

## مثال ۱ — چاپ 1 تا n
```c
int n;
scanf("%d", &n);

for (int i = 1; i <= n; i++) {
    printf("%d\n", i);
}
```
در این مثال، اگر `n<=0` باشد حلقه اجرا نمی‌شود. فرض مسئله را روشن کنید یا ورودی را اعتبارسنجی کنید.

## مثال ۲ — مجموع 1 تا n
```c
int n;
scanf("%d", &n);

int sum = 0;
for (int i = 1; i <= n; i++) {
    sum += i;
}
printf("%d\n", sum);
```

## مثال ۳ — دریافت n عدد و شمارش مثبت‌ها
```c
int n;
scanf("%d", &n);

int count = 0;
for (int i = 0; i < n; i++) {
    int x;
    scanf("%d", &x);
    if (x > 0) {
        count++;
    }
}
printf("%d\n", count);
```

## پرسش‌ها و حالت‌های خاص
1. برای `n=0` و `n=1` چند بار حلقه اجرا می‌شود؟
2. اگر شرط `i <= n` را به `i < n` تغییر دهیم، چه عددی حذف می‌شود؟
3. اگر `i++` حذف شود، چه اتفاقی می‌افتد؟
4. اگر `sum` را داخل حلقه مقداردهی صفر کنیم، خروجی چگونه تغییر می‌کند؟
5. در مثال شمارش، اگر `n=0` باشد، چند عدد خوانده می‌شود؟
6. اگر دنباله شامل `-2, 0, 5, 5` باشد، تعداد مثبت‌ها چند است؟ صفر مثبت محسوب می‌شود؟
7. اگر مقدار n منفی باشد، آیا برنامه نمونه ورودی می‌خواند؟ آیا این رفتار با تعریف مسئله سازگار است؟

## تمرین کلاسی
برنامه‌ای بنویسید که عدد n را بخواند و تعداد رقم‌های آن را محاسبه کند. در نسخه اول فرض کنید n نامنفی است؛ سپس درباره ورودی 0 بحث کنید.

**حالت‌های ویژه:** n=0، n=7، n=1000. اگر فرصت بود، اعداد منفی و خطر استفاده از `-INT_MIN` را فقط به‌عنوان نکته تکمیلی مطرح کنید.

## نکته مدرس
در این جلسه شبه‌کد یا جدول trace مستقل لازم نیست؛ trace را مستقیماً از روی خطوط C انجام دهید: مقدار متغیرها را پس از هر تکرار روی تخته ثبت کنید.

## تکلیف
دو برنامه بنویسید: چاپ مضرب‌های 3 تا n و محاسبه مجموع اعداد زوج از 1 تا n. برای هر کدام n=0، n=1 و یک مقدار معمول را آزمایش کنید.
