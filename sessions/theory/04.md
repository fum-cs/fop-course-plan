# جلسه نظری ۴ — اولین برنامه C و چرخه اجرای آن

**وضعیت:** Prepared (نسخه اولیه؛ هنوز در کلاس آزموده نشده)  
**زمان:** ۱۰۰ دقیقه  
**پیوند Roadmap:** جلسه ۴  
**منبع:** درس‌نامه، بخش ۱، فصل ۳

## هدف‌ها
- ساختار یک برنامه ساده C را بخواند.
- چرخه edit–compile–run را انجام دهد.
- خطای نحوی، زمان اجرا و منطقی را از هم تشخیص دهد.
- برنامه را با ورودی‌های مختلف آزمایش کند.

## طرح زمانی
- ۰–۱۰: مرور نمایش داده؛ پرسش کوتاه.
- ۱۰–۲۵: فایل منبع، تابع `main`، دستور، نقطه‌ویرگول، کامپایلر و executable.
- ۲۵–۴۰: اجرای زنده Hello World؛ سپس برنامه خواندن دو عدد و چاپ مجموع.
- ۴۰–۵۵: خطاهای syntax/runtime/logic؛ نمایش عمدی یک خطا از هر نوع.
- ۵۵–۷۵: تمرین مستقل: خواندن سه عدد و چاپ میانگین؛ توجه به تقسیم صحیح.
- ۷۵–۹۰: بررسی راه‌حل‌ها و تست ورودی‌هایی که میانگین صحیح نیست.
- ۹۰–۱۰۰: مسئله خروج: خواندن عدد و چاپ زوج/فرد، ابتدا الگوریتم و سپس C.

## نمونه کد
```c
#include <stdio.h>

int main(void) {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d\n", a + b);
    return 0;
}
```

در اجرای زنده، مقدار بازگشتی `scanf` را نیز به‌عنوان عادت خوب بررسی کنید؛ در نخستین نمایش می‌توان کد را ساده نگه داشت و سپس نسخه مقاوم‌تر را نشان داد.

## خطاهای قابل نمایش
- حذف `;` یا اشتباه در نام متغیر: syntax/compile error.
- تقسیم بر صفر: runtime failure یا رفتار نامعتبر وابسته به مورد.
- چاپ `a-b` به‌جای `a+b`: logic error.
- استفاده از `scanf` بدون `&` برای متغیر معمولی: خطای رایج.

## تکلیف
دو برنامه کوتاه از فصل ۳ را اجرا کنید؛ یک خطای منطقی را خودتان وارد کنید و در توضیح کوتاه بگویید چگونه آن را پیدا کردید.
