# جلسه نظری ۱ — اولین الگوریتم‌ها در C

**وضعیت:** Prepared — بازنویسی‌شده؛ هنوز در کلاس آزموده نشده  
**زمان:** ۱۰۰ دقیقه  
**پیوند Roadmap:** جلسه ۱  
**منبع:** درس‌نامه، بخش ۱، فصل ۱ و ۳

## هدف‌های یادگیری
در پایان جلسه دانشجو بتواند:
- برنامه C ساده را در محیط مورد استفاده اجرا کند.
- کد را به‌عنوان دستورهای دقیق و متوالی بخواند.
- یک مسئله بسیار ساده را با چند دستور C حل کند.
- برای برنامه، ورودی و خروجی و حالت‌های خاص را مشخص کند.

## قرارداد آغازین
از ابتدا از قالب ثابت استفاده کنید؛ فعلاً فقط دستورات داخل `main` را توضیح دهید:

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

توضیح `#include`، `main` و `return` را به جلسات بعد موکول کنید. در این جلسه فقط بگویید این چارچوب یک برنامه C است و فعلاً دستورات را درون آن می‌نویسیم.

## سناریوی ۱۰۰ دقیقه‌ای
### ۰–۱۰ | آغاز
- برنامه‌نویسی یعنی بیان دستورهای دقیق برای حل مسئله.
- پرسش: کامپیوتر از دستور «دو عدد را جمع کن» چه چیزی باید بداند؟
- پاسخ‌ها را به ورودی، عملیات و خروجی تفکیک کنید.

### ۱۰–۲۵ | اولین برنامه
برنامه Hello World را تایپ، کامپایل و اجرا کنید. سپس متن خروجی را تغییر دهید. فعلاً فقط `printf` و رشته را در حد لازم معرفی کنید.

### ۲۵–۴۰ | دستورهای متوالی
برنامه‌ای که چند پیام را در خطوط جدا چاپ می‌کند. ترتیب دستورات را با جابه‌جایی دو `printf` نشان دهید.

### ۴۰–۵۵ | مثال اصلی: جمع دو عدد ثابت
```c
#include <stdio.h>

int main(void) {
    int a = 7;
    int b = 5;
    int sum = a + b;
    printf("%d\n", sum);
    return 0;
}
```
در این مرحله متغیرها را فقط در حد «نامی برای نگهداری مقدار» معرفی کنید؛ توضیح کامل نوع‌ها در جلسه ۲.

### ۵۵–۷۵ | فکر مستقل و ارائه
مسئله: برنامه‌ای بنویسید که سه عدد ثابت را دریافت‌شده در متغیرها در نظر بگیرد و مجموع آن‌ها را چاپ کند. دانشجویان ابتدا کد خود را بنویسند؛ سپس دو راه‌حل را مقایسه کنید.

### ۷۵–۹۰ | مثال کوچک: تبدیل واحد
```c
int minutes = 135;
int hours = minutes / 60;
int remaining = minutes % 60;
printf("%d:%d\n", hours, remaining);
```
این مثال را به‌عنوان مشاهده اولیه اجرا کنید؛ توضیح کامل `/` و `%` به جلسه ۲ موکول شود.

### ۹۰–۱۰۰ | جمع‌بندی
- کدام خطوط باعث محاسبه می‌شوند و کدام خط نتیجه را چاپ می‌کند؟
- اگر مقدارهای اولیه عوض شوند، آیا الگوریتم همچنان کار می‌کند؟
- آیا خروجی برنامه برای همه ورودی‌های مورد نظر درست است؟

## پرسش‌ها و حالت‌های خاص برای کلاس
1. اگر `a=7` و `b=5` را جابه‌جا کنیم، مجموع چه تغییری می‌کند؟
2. اگر هر دو مقدار صفر باشند چه چاپ می‌شود؟
3. اگر یکی منفی باشد، آیا جمع همچنان درست است؟
4. در برنامه تبدیل ۱۳۵ دقیقه، اگر مقدار ۵۹ یا ۶۰ باشد چه خروجی‌ای انتظار داریم؟ (در جلسه بعد بررسی دقیق‌تر شود.)
5. آیا `printf("%d", a+b)` و ابتدا ذخیره مجموع در متغیر، از نظر خروجی تفاوت دارند؟

## نکته مدرس
از توضیح هم‌زمان همه اجزای زبان پرهیز کنید. هدف جلسه، تجربه اجرای یک برنامه کوچک و دیدن ارتباط بین مسئله، دستورات و خروجی است؛ نه تسلط بر تمام syntax.

## مطالعه/تمرین
درس‌نامه بخش ۱، فصل ۱ را مطالعه کنند. سه برنامه کوتاه با مقادیر ثابت بنویسند: چاپ مستطیل متنی، محاسبه مجموع سه عدد، و تبدیل دقیقه به ساعت و دقیقه. برای هرکدام یک حالت خاص پیشنهاد دهند.


## توافق سبک تدریس — ترتیب شروع و نوع مسئله‌ها

شروع کار از همان جلسه اول با C است: ابتدا نوع int، اعلان متغیر، مقداردهی و انتساب، چهار عمل اصلی و چاپ. بعد از چند مثال، در صورت مناسب بودن زمان، خواندن ورودی و سپس float معرفی می‌شود. توضیح کامل اجزای چارچوب برنامه، حافظه و اجرای برنامه به‌تدریج و در خلال مثال‌ها انجام می‌شود.

مسئله‌های این درس الزاماً کاربردهای دنیای بیرون نیستند. خود الگوریتم، راه‌حل‌های متفاوت برای یک مسئله، محدودیت تعداد متغیرها، جابه‌جایی مقادیر، دقت اعداد اعشاری، سرریز و رفتار C نیز می‌توانند مسئله کلاسی باشند. در هر مورد، دانشجو راه‌حل ذهنی را با الگوریتم و رفتار واقعی برنامه مقایسه می‌کند.
