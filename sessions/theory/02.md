# جلسه نظری ۲ — متغیرها، ورودی/خروجی و عبارت‌ها

**وضعیت:** Prepared — بازنویسی‌شده؛ هنوز در کلاس آزموده نشده  
**زمان:** ۱۰۰ دقیقه  
**پیوند Roadmap:** جلسه ۲  
**منبع:** درس‌نامه، بخش ۲ و فصل ۳

## هدف‌های یادگیری
- متغیر و نوع داده پایه را به کار ببرد.
- با `scanf` ورودی ساده بخواند و با `printf` چاپ کند.
- عملگرهای حسابی و باقیمانده را استفاده کند.
- تفاوت تقسیم صحیح و حقیقی را با مثال توضیح دهد.
- خطای ناشی از مقداردهی اولیه یا تبدیل نوع را تشخیص دهد.

## چارچوب آغازین
از همان قالب جلسه اول استفاده کنید. امروز فقط `int`، `scanf`، `printf` و عملگرها را به اندازه نیاز توضیح دهید.

## طرح زمانی
- ۰–۱۰: مرور برنامه جلسه قبل؛ تغییر مقدارها و پیش‌بینی خروجی.
- ۱۰–۲۵: متغیر، مقداردهی، نوع `int` و `double`، عملگر assignment.
- ۲۵–۴۰: `scanf` و `printf`؛ توضیح `&` در `scanf` در حد کاربرد فعلی.
- ۴۰–۵۵: عملگرهای `+`، `-`، `*`، `/` و `%`.
- ۵۵–۷۰: تقسیم صحیح، تقدم عملگر و پرانتز.
- ۷۰–۸۵: تمرین مستقل و ارائه چند راه‌حل.
- ۸۵–۱۰۰: حالت‌های مرزی و مسئله خروج.

## مثال ۱ — جمع دو عدد ورودی
```c
#include <stdio.h>

int main(void) {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d\n", a + b);
    return 0;
}
```
در نسخه نخست، ورودی معتبر فرض شود؛ سپس بررسی کنید چرا باید مقدار بازگشتی `scanf` را در برنامه‌های مقاوم بررسی کرد.

## مثال ۲ — رقم یکان و دهگان
```c
int n;
scanf("%d", &n);
printf("ones = %d\n", n % 10);
printf("tens = %d\n", (n / 10) % 10);
```
فعلاً مسئله را برای عدد صحیح نامنفی تعریف کنید؛ رفتار اعداد منفی را به‌عنوان پرسش مطرح کنید، نه فرض پنهان.

## مثال ۳ — تقسیم صحیح در برابر حقیقی
```c
int a = 7, b = 2;
printf("%d\n", a / b);       // 3
printf("%.1f\n", (double)a / b); // 3.5
```

## پرسش‌ها و حالت‌های خاص
1. برای `a=7,b=2` مقدار `a/b` و `a%b` چیست؟ چرا؟
2. اگر `a=8,b=2` باشد، باقیمانده چه می‌شود؟
3. اگر `b=0` باشد، چه مشکلی رخ می‌دهد؟ (تقسیم بر صفر مجاز نیست.)
4. اگر میانگین دو عدد 7 و 2 را با `(a+b)/2` در متغیر `int` ذخیره کنیم، چه مقدار از دست می‌رود؟
5. در برنامه تبدیل دقیقه، ورودی 59، 60، 61، 119 و 120 را آزمایش کنید.
6. اگر ورودی خارج از محدوده `int` باشد یا ورودی به‌جای عدد متن وارد شود، چه تضمینی داریم؟ توضیح اولیه: در این برنامه ساده هنوز اعتبارسنجی ورودی را کامل نکرده‌ایم.

## تمرین کلاسی
برنامه‌ای بنویسید که مبلغی را بر حسب سنت دریافت کند و آن را به تعداد دلار و سنت باقی‌مانده تبدیل کند. فرض کنید ورودی نامنفی است.

حالت‌های خاص: 0، 99، 100، 101 و مقدار دقیق چند دلار.

## تکلیف
برنامه‌های ساده محاسباتی از درس‌نامه را اجرا کنید. برای هر برنامه، یک ورودی معمول و دو ورودی مرزی بنویسید و خروجی مورد انتظار را پیش از اجرا پیش‌بینی کنید.


## ترتیب تدریس مورد توافق برای شروع

1. اعلان و مقداردهی متغیرهای int.
2. انتساب و تغییر مقدار متغیر.
3. چهار عمل اصلی و چاپ نتیجه.
4. مسائل کوچک با مقدارهای ثابت؛ از جمله مجموع/ماکزیمم پنج عدد با تعداد متغیرهای متفاوت و جابه‌جایی دو متغیر.
5. پس از چند مثال، خواندن ورودی با scanf.
6. معرفی float یا double و بررسی تفاوت محاسبه صحیح و اعشاری.
