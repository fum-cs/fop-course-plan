# جلسه نظری ۲ — مرور شروع C، متغیرها، محاسبه و ورودی

**وضعیت:** Prepared — پیش‌نویس بازنگری‌شده؛ هنوز در کلاس آزموده نشده  
**زمان:** ۱۰۰ دقیقه

## هدف‌های یادگیری
- بازیابی محتوای اصلی جلسه اول، به‌ویژه برای غایبان.
- به‌کارگیری int، اعلان، مقداردهی اولیه، انتساب، محاسبه و چاپ.
- مقایسه چند راه‌حل از نظر تعداد متغیر و تعمیم‌پذیری.
- خواندن ورودی ساده با scanf و آشنایی اولیه با float/double.

## طرح زمانی
- **۰–۱۵ | مرور جلسه اول:** اجرای برنامه Welcome/Hello؛ مرور int و چاپ؛ تغییر مقدارها و پیش‌بینی خروجی. این بخش نقش ورود به درس را برای غایبان دارد.
- **۱۵–۳۵ | اعلان، مقداردهی، انتساب و محاسبه:** trace دستورها و تفاوت اعلان، مقداردهی و انتساب؛ توضیح مقدماتی مقدار، حافظه و اجرای ترتیبی.
~~~c
int a = 7;
int b = 5;
int sum = a + b;
sum = sum + 1;
printf("sum = %d\n", sum);
~~~
- **۳۵–۵۵ | مسئله با مقدار ثابت:** مجموع پنج عدد، ابتدا با متغیرهای جدا و سپس با accumulator؛ مقایسه تعمیم‌پذیری. جابه‌جایی دو مقدار با متغیر کمکی و بررسی نسخه بدون متغیر کمکی به‌عنوان چالش. محدودیت‌ها مانند دامنه مقدار و سرریز را مطرح کنید.
- **۵۵–۷۵ | ورودی:** خواندن دو int و چاپ مجموع. & در scanf فقط در حد کاربرد فعلی توضیح داده شود؛ ورودی معتبر به‌عنوان فرض نسخه نخست مشخص شود.
~~~c
int x, y;
scanf("%d %d", &x, &y);
printf("sum = %d\n", x + y);
~~~
- **۷۵–۹۰ | float و تقسیم:** در صورت رسیدن زمان، تقسیم صحیح در برابر حقیقی را نشان دهید و float/double را معرفی کنید. جزئیات دقت اعشاری به جلسه بعد منتقل شود.
~~~c
int a = 7, b = 2;
printf("%d\n", a / b);
printf("%.1f\n", (double)a / b);
~~~
- **۹۰–۱۰۰ | پرسش خروج:** مقدار sum پس از انتساب چیست؟ چرا accumulator قابل تعمیم است؟ تفاوت 7/2 صحیح و حقیقی چیست؟ چه فرضی درباره ورودی scanf داشتیم؟

## اگر زمان کم آمد
اولویت: مرور جلسه اول، اعلان/انتساب، محاسبه و چاپ. float و تقسیم حقیقی یا بخشی از جابه‌جایی بدون متغیر کمکی به جلسه سوم منتقل شود. در این جلسه وارد اعتبارسنجی کامل ورودی و جزئیات اشاره‌گر نشوید.
