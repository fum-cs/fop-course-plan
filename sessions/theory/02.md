# جلسه نظری ۲ — شبه‌کد، trace و طراحی مرحله‌ای

**وضعیت:** Prepared (نسخه اولیه؛ هنوز در کلاس آزموده نشده)  
**زمان:** ۱۰۰ دقیقه  
**پیوند Roadmap:** جلسه ۲  
**منبع:** درس‌نامه، بخش ۱، فصل ۱

## هدف‌های یادگیری
- الگوریتم را با شبه‌کد یا فلوچارت بیان کند.
- اجرای الگوریتم را با trace بررسی کند.
- متغیرهای حالت و مقدار اولیه را درست انتخاب کند.
- راه‌حل را با یک ورودی معمول و یک ورودی مرزی اعتبارسنجی کند.

## طرح زمانی
- ۰–۱۰: مرور الگوریتم جلسه قبل؛ یک راه‌حل دانشجو روی تخته.
- ۱۰–۲۵: شبه‌کد، assignment، شرط و تکرار به‌صورت مستقل از C.
- ۲۵–۴۵: trace جمع ۱ تا n با جدول `i` و `sum`.
- ۴۵–۶۰: تمرین مستقل: تعداد اعداد مثبت در دنباله‌ای با sentinel صفر.
- ۶۰–۷۵: تحلیل راه‌حل‌ها؛ توجه به ترتیب به‌روزرسانی شمارنده و شرط توقف.
- ۷۵–۹۰: مسئله چالشی: بیشینه و دومین بیشینه (تعریف دقیق حالت تساوی).
- ۹۰–۱۰۰: مسئله خروج و جمع‌بندی.

## تخته: قالب پیشنهادی trace
| گام | i | sum | شرط ادامه |
|---|---:|---:|---|
| آغاز | 1 | 0 | 1 ≤ n |
| تکرار اول | 2 | 1 | 2 ≤ n |
| تکرار دوم | 3 | 3 | 3 ≤ n |

## خطاهای مورد انتظار
- مقداردهی اولیه نامناسب.
- تغییر شمارنده در جای نادرست.
- توقف نکردن در sentinel.
- نادیده گرفتن n=0 یا دنباله خالی.
- استفاده از «عدد بعدی» بدون تعریف دقیق دریافت ورودی.

## پرسش‌های کلاس
1. اگر افزایش i قبل از جمع انجام شود، trace چگونه تغییر می‌کند؟
2. چه ورودی‌ای الگوریتم را زودتر از انتظار متوقف می‌کند؟
3. آیا الگوریتم برای n=0 درست است؟

## تکلیف
یک الگوریتم برای محاسبه تعداد رقم‌های یک عدد صحیح غیرمنفی بنویسید؛ برای 0 و یک عدد چندرقمی trace ارائه کنید.
