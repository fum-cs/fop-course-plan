# جلسه نظری ۳ — تصمیم‌گیری با if و else

**وضعیت:** Prepared — بازنویسی‌شده؛ هنوز در کلاس آزموده نشده  
**زمان:** ۱۰۰ دقیقه  
**پیوند Roadmap:** جلسه ۳  
**منبع:** درس‌نامه، بخش ۳

## هدف‌های یادگیری
- شرط را با `if`، `else if` و `else` پیاده‌سازی کند.
- عملگرهای مقایسه و منطقی را به کار ببرد.
- بازه‌ها را بدون شکاف یا هم‌پوشانی تعریف کند.
- برای مسئله شرطی، ورودی‌های مرزی و تساوی را آزمایش کند.

## طرح زمانی
- ۰–۱۰: مرور عملگرها؛ پیش‌بینی خروجی عبارت‌های مقایسه‌ای.
- ۱۰–۲۵: `if` و بلوک `{}`; اجرای زنده شرط ساده.
- ۲۵–۴۰: `if/else` و چند شاخه.
- ۴۰–۵۵: ترکیب شرط‌ها با `&&`، `||` و `!`.
- ۵۵–۷۵: مسئله کوتاه و ارائه راه‌حل‌های دانشجویان.
- ۷۵–۹۰: آزمون ورودی‌های مرزی و یافتن خطای شرط.
- ۹۰–۱۰۰: جمع‌بندی و مسئله خروج.

## مثال ۱ — مثبت، منفی یا صفر
```c
int x;
scanf("%d", &x);

if (x > 0) {
    printf("positive\n");
} else if (x < 0) {
    printf("negative\n");
} else {
    printf("zero\n");
}
```

## مثال ۲ — بیشینه دو عدد
```c
int a, b;
scanf("%d %d", &a, &b);

if (a > b) {
    printf("%d\n", a);
} else {
    printf("%d\n", b);
}
```
در حالت تساوی، این برنامه مقدار b را چاپ می‌کند که از نظر مقدار درست است؛ اگر قرار باشد محل یا شناسه عدد برنده هم گزارش شود، تعریف مسئله باید تساوی را تعیین کند.

## مثال ۳ — نمره و بازه
```c
int score;
scanf("%d", &score);

if (score < 0 || score > 20) {
    printf("invalid\n");
} else if (score >= 17) {
    printf("A\n");
} else if (score >= 14) {
    printf("B\n");
} else if (score >= 10) {
    printf("C\n");
} else {
    printf("F\n");
}
```

## حالت‌های خاص برای بحث
1. در مثال مثبت/منفی، ورودی صفر را آزمایش کنید؛ چرا شرط‌های `x>=0` و `x<=0` اگر به ترتیب نامناسب نوشته شوند ممکن است شاخه درست را اجرا نکنند؟
2. برای بیشینه دو عدد، ورودی‌های `(3,5)`، `(5,3)` و `(4,4)` را بررسی کنید.
3. در نمره، 0، 9، 10، 13، 14، 16، 17، 20 و 21 را آزمایش کنید.
4. اگر شرط اول `score > 20` باشد و شرط دوم `score >= 17`، آیا 21 به‌درستی رد می‌شود؟
5. اگر از دو `if` مستقل استفاده کنیم، چه تفاوتی با `if/else if` دارد؟
6. آیا شرط `x > 0 && x < 10` عدد 0 و 10 را می‌پذیرد؟

## تمرین کلاسی
سه عدد را بخوانید و کوچک‌ترین را چاپ کنید. دانشجویان باید حالت‌های تساوی را مشخص کنند و راه‌حل خود را با ورودی‌های مساوی آزمایش کنند.

## نکته مدرس
در هر مسئله شرطی، ابتدا مجموعه حالت‌ها را شفاهی نام‌گذاری کنید و سپس شرط‌ها را در C بنویسید. این کار مانع از نوشتن شرط‌های مبهم یا ناقص می‌شود.

## تکلیف
برنامه تعیین نوع مثلث از روی سه طول را بنویسید. ابتدا ورودی نامعتبر (طول غیرمثبت یا نقض نامساوی مثلث) را تشخیص دهید؛ سپس متساوی‌الاضلاع، متساوی‌الساقین یا مختلف‌الاضلاع را تعیین کنید. حالت‌های تساوی و مرز نامساوی مثلث را در آزمون‌ها بگنجانید.
